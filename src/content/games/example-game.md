This file exists to show the schema a real game entry should follow. It has
`status: example`, so it never shows up on the live site or in listings —
only entries with `status: live` or `status: coming-soon` do.

When the `/publish` skill creates a real entry, it fills in the same fields:
`title`, `summary`, `status`, `date`, `tags`, `tier`, and `links`, plus a body
like this one describing how to play it.
