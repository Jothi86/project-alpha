A ranked table of the top US-listed stocks by a blended value/quality/dividend
composite score, with Piotroski F-Scores and value catalysts flagged per name. Tap a
row for the full metric set and headlines; star names into a watchlist that persists
in the browser.

The underlying data refreshes automatically every night from a ~6,000-symbol database.
Install it to your phone's home screen (Share → Add to Home Screen on iOS, ⋮ → Install
app on Android) for an app-like experience that keeps working offline on the last
data it downloaded.
